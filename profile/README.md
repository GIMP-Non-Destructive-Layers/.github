## Overview

GIMP Non-Destructive Layers is a professional image editing concept built around editable, quality-preserving workflows. ## Essential Non-Destructive Features

- **Link Layers:** Incorporate external images into compositions and scale, rotate, or transform them without losing quality or sharpness; the layer updates automatically when the source file changes [citation:1][citation:2].
- **Vector Layers:** Use the Path tool to create shapes with adjustable fill and stroke settings that remain fully editable and scalable [citation:1][citation:5].
- **Non-Destructive Filters:** Apply filters to layers, layer groups, and individual channels without permanently altering the underlying data [citation:4][citation:12].
- **Rasterize Safety Latch:** Destructive edits require explicit rasterization, and Revert Rasterize restores the layer to its editable state [citation:4].
- **SVG and PDF Vector Export:** Export Vector Layers and text layers as real vectors to SVG, with expanded vector options in PDF export [citation:5][citation:13].
- **PSD Compatibility:** Import more layer styles from Photoshop files, improving interoperability with Adobe workflows [citation:1][citation:12].

## What Non-Destructive Layers Bring to Image Editing

The workflow shifts the editing model from permanent pixel changes to editable, reversible operations. Link Layers function similarly to Photoshop Smart Objects, allowing external assets to remain connected and updatable without manual re-import [citation:12].

Vector Layers replace the older path-to-selection approach. Paths can now become full layers with fill and stroke properties, remaining editable through scaling and transformation operations [citation:5].

Filter flexibility extends across the layer stack. Non-destructive filters can be applied to channels in addition to layers and groups, keeping adjustments live until deliberately committed [citation:4].

The rasterize latch adds a safety net. When a user attempts a destructive edit on a non-destructive layer, GIMP requires rasterization first; if the result is unsatisfactory, Revert Rasterize clears the destructive changes and restores editability [citation:4].

Export options connect the workflow with other tools. SVG export now produces actual vectors from Vector Layers and text, and PDF export preserves vector editability in compatible software [citation:5][citation:13].
